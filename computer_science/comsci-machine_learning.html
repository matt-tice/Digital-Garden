Structure

Works with multidimensional immutable arrays (which they call tensors)

  • If T is the set of tensors, then a layer is map
  • f: Tn → T

Layers are objects with the following methods

  • init: create custom layer attributes and weights that don't depend on the input shapes
  • build: creates weights that do depend on the input shapes
  • call: performs the computation

Layers

Some standard layers are

  • flatten: turns array into a long vector
  • dense: densely connected neural layer

Pre-processing

If you're working with images, normalize the data, so that the pixels are all given values between 0 and 1
