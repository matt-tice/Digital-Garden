Summary

Functions are objects

  • so they can be assigned to variables, passed as arguments, returned, and stored in data structures

Higher order functions take functions as inputs

  • this is used in functional programming
def fun(f, x):
  return f(x)

Decorators

Functions that take other functions as arguments

  • @decorator is short for
  • function = decorator(function)
def decorator(f):
  def wrapper(*args, **kwargs):
     ...
     f()
     ...
  return wrapper

@decorator
def funct():

Use-Cases

Logging: track function calls

Authentication: restrict access in certain circumstances

Rate limiting: control usage per user

Caching: store results

Retry logic: automatically retry failed attempts

Default Values

def function(x, y=3):

You can call this with function(1), and it will have x=1, y=3 Or you can overwrite y, with function(1,5)

Note that the default value is only evaluated once

  • so if you call a function multiple times, the default won't reset
  • the default will become whatever it ended up as the last time the function was called

You can pass only specific variables by naming them when you call the function. The naming version is called keywords

def function(x, y=2, z = 5):
...

function(1, z = 7)

def f(pos, /, pos_or_key, *, key):

The symbols / and * are optional and they tell you whether you're allowed to pass in positional or keyword arguments Without those symbols, you can pass everything by position or keyword

Use-cases

Positional-only

  • if you don't want user to have the parameter names (ex. the names have no real meaning)
  • for API, to prevent breaking API changes if the parameter's name is modified in the future

Keyword-only

  • when names have meaning and function def is more understandable when you're explicit

Tuple Arguments

You can set a function to accept arbitrarily many arguments (which will be placed in a tuple)

  • use asterisk before variable name
  • these variadic arguments go at the end of the function definition
def f(x,y, *t):

You can actually call a function with a list or tuple, and unpack the sequence

def f(x,y):

f(*[1,2])

Dictionary Arguments

def f(x, *t, **d):

f(1, 2, 3, person = 'tom', rival = 'sue')

Generator Functions

They produce iterators

  • things like range()
  • things that a for loop can iterate over

Each time the function is called, it

  • loads its current state
  • does stuff
  • saves its new state
  • returns the new state (using the yield keyword)
    • when the code reaches yield, it returns the new state and pauses
    • the next time the function is called it continues from right after the yield command
def fibonnaci():
  x,y = 0, 1

  while True:
     yield x + y
     x, y = y, x+ y

Benefits

Saves memory since it generates on-the-fly

Chain generators to process data in stages efficiently

Create arbitrarily long sequences
