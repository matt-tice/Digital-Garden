Summary

In this file I'll record some of the things I've learned about emacs usage — tips, tricks, debugging, etc.

Rectangles

Registers

They store things:

  • Text
  • Rectangles
  • Buffer names
  • Frame configs
  • File names

Each register has a single letter as its name

Bookmarks

Lets you jump to specific files or directories very quickly It saves them forever, unlike registers

Latex

Auctex has two different (similar) modes:

  • latex-mode
  • tex-mode

As it turns out, you need both of them

  • tex-mode is the thing that lets you compile and such
  • latex-mode

Keybindings

You can remove keybindings with

global-unset-key local-unset-key

Similarly, you can set them with

global-set-key local-set-key

Org-Agenda

You can add agenda files by going to the relevent file and typing M-x org-agenda-file-to-front

  • C-c [

And remove them with M-x org-remove-file -C-c ]
