Summary

HTML is a markup language

Tags

Non-semantic tags are general ones that don't tell you anything specific about the element

Html

Top-level element

  • contains the global attributes
  • specifies the version of html
  • specifies XML namespace

Metadata

Base

Specifies the base URL for all relative ones

  • can only be one of these

Head

Contains info like title, scripts, and style-sheets

Link

Specifies relationship between current document and an external resource

  • used to link to CSS

Style

CSS info that will impact only this page

Title

Document title shown in the browser title bar

Meta

Other metadata that doesn't fall into one of the above categories

Body

Contains the content of the document

  • can only be one of these

Content

Address

Contact info

Article

Self-contained composition

  • intended to be independent or reusable
  • ex. forum post, blog entry, comment, widget

Aside

Only indirectly related to the main content

  • usually presented as side-bars or call-out boxes

Footer

Footer for the nearest ancestor

  • typically contains info on author of the section, copyright data, or links to related documents

Header

Intro content

  • navigation buttons/menus, logo, search bar, author's name

h1, h2, …

Section heading levels (h1 is the highest)

Hgroup

Heading grouped with secondary content

  • subheadings, alterative title, tagline
  • ex. a heading that says Frankenstein [and then as a subtitle] Or: The Modern Prometheus

Main

The main content

Nav

Navigation menus, tables of contents, indexes

Section

Generic standalone section

  • should always have a heading

Search

Searching or filtering
