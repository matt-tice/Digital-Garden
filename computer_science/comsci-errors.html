(defun my/org-publish-by-directory ()
  "Publishes each subdirectory as its own 'mini-batch' to prevent pipe exhaustion."
  (interactive)
  (let* ((base-dir "~/Org-Roam/Public")
         ;; Get a list of all subdirectories (non-recursively)
         (subdirs (directory-files base-dir t "^[^.]" t)))

    ;; 1. Process the files in the root directory first
    (message "Publishing Root Directory...")
    (org-publish-project "digital-garden-notes" nil) ; Temporary non-recursive

    ;; 2. Loop through each sub-folder
    (dolist (dir subdirs)
      (when (file-directory-p dir)
      ;; SANITIZE: Replace colons and slashes with underscores for the cache name
      (let* ((clean-name (replace-regexp-in-string "[:/]" "_" dir))
             (tmp-project-name (concat "tmp-" clean-name))
             (org-publish-project-alist
              `((,tmp-project-name
                 :base-directory ,dir
                 :base-extension "org"
                 :publishing-directory "~/Public-Export/"
                 :publishing-function org-gfm-export-to-markdown
                 :filter-functions (my/org-export-private-to-stub)))))
        (message "Safely publishing: %s" dir)
        (org-publish-project tmp-project-name t))
      (garbage-collect)))))

the problem is the Initializing asynchronous export process

  • emacs spawns these asynchronous child processes, which hang around until the full emacs loop finishes everything
  • so even though we tried to do everything directory by directory, it ends up just opening all of the files in pipes anyway

This is resourcee contention

  • two agents (emacs and windows) are fighting over the same file handles
  • emacs tries to work asynchronously, but Windows is too slow
  • so we have to rate-limit emacs to the speed of Windows

The problem might be the cache

  • the unique names tmp- get a persistent handle
  • so we want to clear the cache at each dolist iteration
  • and also we might as well just use a persistent project name, so we don't keep adding new tmp-project-name folders
