* Summary



Key-value pairs are denoted

#+begin_src  yaml
key: value
#+end_src

Lists are denoted with a hyphen for the first element

#+begin_src yaml
steps:
  - name: Checkout
    uses: actions/checkout@v4
#+end_src


To run multiple commands, use a literal indicator =|= or a folded indicator =>=

#+begin_src yaml
run: |
  echo "Starting build..."
  mingw32-make

run: >                          # Collapses line breaks
  echo "This whole thing
  becomes on single long sentence"
#+end_src
