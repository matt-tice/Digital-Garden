* Arch Linux

** initramfs

During boot, the bootloader takes a compressed archive (.img) from the Z: drive and decompresses it into a RAM disk containing all the drivers and tools needed to start the system

Execution vs. Storage: Modern OS installers utilize an initrd/initramfs (Initial RAM Disk) to decouple the Operating System from the physical media. This "Cold Boot to RAM" state is what allows for non-destructive filesystem manipulation, as the underlying hardware is not locked by the running kernel's I/O operations.
- it's a 2-stage boot
- Windows has WinPE and Winload


The RAM-Disk Universal: All modern operating systems utilize a TEE (Temporary Execution Environment) in RAM to bridge the gap between hardware initialization and filesystem mounting. This decoupling is a mechanical necessity for handling driver diversity and performing "cold" system maintenance.

Partition Truncation: A filesystem whose internal metadata reports a size larger than its containing partition is considered "malformed." While non-destructive to the underlying data, it results in a boot failure. The remedy is a manual correction of the Partition Table to match or exceed the filesystem's reported boundaries.
