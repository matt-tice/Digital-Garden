* Commands

** push

** pull

Runs =git fetch= followed by =git merge=

*** fetch

Downloads the latest history from Github
Does nothing to the working files
- just updates git's local copy of what the remote repo looks like
- this info is stored in =origin/main=

*** merge

Creates a merge commit, forcing multiple different repo histories together

** add

** commit

** rebase

This is a linear alternative to merge
- finds the most recent common ancestor of the local repos, plugs in those commits first and then reapplies your current comits.

** diff

Compares different commits, allowing you to find the modified files

Use =--name-only= if you don't want to output the raw text changes, but just grab the paths of the changed files
