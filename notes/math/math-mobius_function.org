* Definitions

** Incidence coalgebra of a poset

Let \(L\) be a locally finite poset. We define a vector space \(C(L)\), generated by all of the intervals in \(L\). The *incidence coalgebra* is \(C(L)\) with the comultiplication

\[
\Delta([x,z]) = \sum_{y \in [x,z]} [x,y] \otimes [y,z]
\]
and counit
\[
\varepsilon([x,x]) = 1
\]
\[
\varepsilon ([x,y]) = 0
\]

*** Convolution algebra

The convolution algebra \(L(C)^{*}\) has as elements linear functionals, which multiply as

\[
(\phi *  \psi)[x,z] =  \sum_{y \in [x,z]} \phi[x,y] \psi[y,z].
\]

*** Zeta function

The *zeta function* \(\zeta \in C(L)^{*}\) is defined as the constant function on all intervals
\[
\zeta[x,y] = 1
\]

*** Mobius function

The *möbius function* \(\mu \in C(L)^{*}\) is the multiplicative inverse of the zeta function
\[
\mu * \zeta = \zeta * \mu = \varepsilon 
\]

So
\[
\varepsilon[x,y] = \sum_{y \in [x,z]} \mu[x,y] = \begin{cases}
1, \quad x = y \\
0, \quad x < y
\end{cases}
\]




** Möbius function

Let \(L\) be a lattice. The *möbius function* \(\mu: L \times L \rightarrow \mathbb{Z}\) is defind recursively by

\(\mu(x,x) = 1\)
\(\mu(x,y) = - \sum_{x \leq z < y} \mu(x,z) \)

** Counting chains in an interval

\((\zeta - \varepsilon )^{n}[x,y]\) is the number of chains of length \(n\) in \([x,y]\).

*** Proof

\[
(\zeta - \varepsilon )^{n}[x,y] = \sum_{w \in [x,y]} 
\]
