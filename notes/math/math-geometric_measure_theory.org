* Currents

We view measures as 0-chains in a chain complex. 
- really they're distributions

Higher-dimensional chains are called *currents*.

Let $\mathcal{D}^{k}(M)$ be the smooth, compactly supported $k$-forms on $M$. A *k-current* is a continuous linear functional
\[
\phi: \mathcal{D}^{k}(M) \to
\] F
 
The space of currents is denoted with a subscript: $\mathcal{D}_{k}$ 


\[
\partial \phi(_{}\omega) = \phi(d \omega)
\]

Given a measure $\mu$, we define an $n$-current for each measurable set by
\[
\phi_{E}(\omega) = \int_{E} \omega
\]

Null sets are then the zero elements of the chain complex
