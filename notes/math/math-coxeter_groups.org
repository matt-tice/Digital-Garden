* Summary

Coxeter groups are those groups that have presentations of the form

$\langle x_{0}, \ldots, x_{n} \mid (x_{i} x_{j})^{m_{ij}} = 1\rangle$, where $M$ is a symmetric matrix with 1s on the diagonal (so $x_{i}^{2} = 1$).

This determines a graph, called the *Coxeter-Dynkin graph* 

Note that for $i \ne j$ we must have $m_{i}_{j} \geq 2$, since if $m_{i}_{j} = 1$, that implies $x_{i} x_{j} = 1$ so $x_{i} = x_{j}^{-}^{1} = x_{j}$.

When drawing the Coxeter-Dynkin graph you
- don't draw any edges with $m_{i}_{j} \leq 2$
- leave the $m_{i}_{j} = 3$ edges unlabelled
- label the rest of the edges.
