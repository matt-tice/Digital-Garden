** home

Home directors for the user

This can be used for whatever you want, but I've found that it's actually nicer to use your /home directory as something like /etc, but for different kinds of things.

Whereas the root version of /etc has configurations for the root, /home has *configurations for the user*

Then you create a separate /data directory or partition, and use that for your actual files
- and in fact, you can separate that directory further, by creating subdirectories like
- /archive - for read-only files
- /workspace - for your actively read/written files
- /storage - for 3rd party/closed-source binaries

* Bootloader

When you install an OS, the installer writes the bootloader onto the hard drive
- the bootloader connects to the kernel

  
** Firmware

Modern motherboards come preloaded with public keys from the manufacturer

The bootloader needs to be digitally signed with a matching private key

*** BIOS

Can't read files
It *always looks at the first 512 bytes* of a disk
- this is called the *Master Boot Record*

**** Master Boot Record

If the first sector (512 bytes) ends in the bytes 0x55 and 0xAA, the BIOS recognizes it as a bootloader
- it then starts executing the 512 bytes

***** Insecure

You can just write a malicious program in assembly and end it with 0x55AA

These kinds of malware are called *Bootkits*
