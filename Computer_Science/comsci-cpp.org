+ Makes it much faster than an interpretted language (like Python)

Has flexibile memory management
+ In Java, some of the system memory is used to interpret the language
       + A garbage collector is used to tidy up the memory
       + You don't have direct control over how much memory is used
+ In C++ you know how much memory a program will use

Pointed chasing and virtual method look-up slow down C++ in comparison to Fortran

* Debugging

C++ has some features to aid in debugging your program

** <cassert>

assert will check whether a particular statement is true, and if not, it will exit the program, pointing to the issue

asserts are automatically removed when compiled with the -O flag, to optimize your code, which is awesome --- once you know it works, you can drop the asserts
