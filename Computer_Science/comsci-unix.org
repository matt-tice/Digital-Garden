* Summary

UNIX is designed around a few key concepts
- programs should be simple and should do *one single task* each
- programs should be *linkable*
- the kernel should be as small as possible
- all other tasks are the responsibility of the shell

* Shell

Interface between the user and the kernel

There've been a whole bunch of shells over the years. Most of them are based on the Bourne shell
- Bourne shell (sh)

       + Bourne again shell  (bash)
