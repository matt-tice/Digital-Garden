* np.indices

Notoriously confusing, I think I'm starting to get what it is

If you take, say (m,n) as dimensions, and do

#+begin_src 
A = numpy.indices((m,n))
#+end_src

what you'll get is an array with dimensions *2 x m x n*
And in particular, the entry
#+begin_src 
(A[0, i, j], A[1, i, j]) == (i,j)
#+end_src

What is the purpose of this? I don't really know

But here's something you can do with it
- if you want a matrix whose entries are written in terms i and j, you can build that pretty quickly with this array

  #+begin_src
    # make a matrix with whose entries are the products of the indices

dim = (m,n)
A = np.indices(dim)

    # we have mat[i,j] = A[0, i, j] * A[1, i, j], which can be coded as

mat = np.prod(A, axis=0)    
  #+end_src
