* Types

** ext4

Predominately used on Linux.

When files are modified, the modified data gets overwritten with the new version by the file system.

During the overwriting process, the file system saves a log of what's being done, so that if the system crashes, the data can be recovered.

** BTRFS

The main feature of this file systm is that it does Copy-on-Write (CoW).
- when a file is modified, the new version does not overwrite the original file;
- instead, it's saved to an entirely new position in memory.
- then the old version of the file is marked as trash that the garbage collector can deal with at a later time.

** NTFS

A Windows proprietory system. It's the standard file system that is used in devices.

Like ext4, data is overwritten when a file is modified.
