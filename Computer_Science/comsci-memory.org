** RAM

*** Dynamic RAM

Cheaper
+ each bit of info goes in a single capacitor
+ single transistor for each bit

Even if it has power, the data in DRAM decays in seconds
+ charge leaks out of the capacitor
  
So it has to be *refreshed*
+ you read the data of each bit and immediately write it again
+ when you write it, the charge on the capacitor is reset

*** Static RAM

Faster
+ each bit corresponds to 6 transistors
+ used for cpu cache
+ used for processor registers

Data is stored in *flip-flops*
