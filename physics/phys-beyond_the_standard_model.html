Strong CP Problem

We can add a CP-violating interaction to the standard action of QCD

  • The coupling parameter that shows up is the Yang-Mills instanton number

The strong CP problem is why the coupling parameter is so small

  • Another way of thinking about this is, why does QCD look like it preserves CP-symmetry?
  • If the coupling parameter were larger, we would be able to see CP violation
  • And in fact, in experiment, we've never seen CP violation in QCD due to the strong force.
    • We only have CP violations from the weak force

Solutions

  1. The up quark mass is zero
    • This seems to be false
  2. CP might be valid microscopically but spontaneously break in such a way that the coupling parameter is small
    • This is a nice solution because it actually predicts something we can test for
  3. The coupling parameter can relax spontaneously to a small value if axions exist

Swampland Conjectures

No Global Symmetries

Conjecture: A theory coupled to gravity must have no global symmetries, and thus are broken or gauged

Completeness

Conjecture: A gauge theory coupled to gravity must have physical states for each possible gauge charge

  • This implies that you have to work with compact Lie groups or discrete gauge groups

Swampland Cobordism

Conjecture: Any quantum gravity theory compactified on a d-dimensional internal manifold has a corresponding quantum-gravity cobordism group which vanishes in degree d.
