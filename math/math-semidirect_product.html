Summary

A semidirect product of the form N : H is group action of H on N

Homomorphism H → Aut(N)

For Zq : Zpn The intersection of all sylow p-subgroups (the p-core) is the kernel of the action map Zpn → Aut(Zq)

The action is always by conjugation so being in the kernel is equiv to xgx-1 = g, or xg = gx

So the kernel is exactly those elements of Zpn that commute with all of Zq

Now we show it's the p-core

  1. The kernel is a subgroup of Zpn by construction (since we map out of Zpn)
  2. So the kernel is a p-subgroup (power pk)
  3. Then it's contained in some sylow p-subgroup
  4. Since the kernel is normal and all sylow p-subgroups are conjugate, it follows that the kernel is in all of the sylow p-subgroups
  5. The kernel is therefore in the p-core

Now consider any element not in the kernel, x

  1. So there is some g in Zq with xg ≠ gx
  2. Since Zq is cyclic and generated by any non-trivial element, this implies that x can't commute with any element of Zq
  3. If x was in two sylow p-subgroups P1, P2 then take an element of Zq that sends one to the other so x = g p g-1
