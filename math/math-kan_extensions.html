Summary

Intuition: Kan extensions are something like generating from a basis. If you have some collection of nice objects, you want to extend to a full category of objects built up out of those nice building blocks

Left Kan extension: Uses colimits to generate by gluing generators together

Right Kan extension: Uses limits to restrict the nice objects to

Definitions

Left Kan extension

Let F : 𝒞 → 𝒟 and G : 𝒞 → ℰ be functors. A left Kan extension is a pair (L, η), where η : G ⇒ FL such that for any ϕ : G ⇒ FX there's a unique map δ : L ⇒ X with ηδL = ϕ

Intuition

FL is the smallest thing larger than G, so we map into FL, and any other thing larger than G has to hit FL first

Notation: I'm going to write LF[G] to denote the left Kan extension of F along G. This is backwards to the normal way that it's notated, but I like that we get a kind of Einstein summation thing happening: ε : G ⇒ FLF[G]

Right Kan extension

Let F : 𝒞 → 𝒟 and G : 𝒞 → ℰ be functors. A right Kan extension is a pair (R, ε), where ε : FR ⇒ G such that for any other ϕ : FX ⇒ G, there's a unique map δ : X ⇒ R with δFε = ϕ

Intuition

FR is the largest thing smaller than G, which is why we map into G, with ε : FR ⇒ G, and every other thing mapping into G has to first map into FR

Notation: I'll denote by RF[G] the right Kan extension of F along G, so that we have η : FRF[G] ⇒ G

Examples

Limits

Let 1 be the terminal category with a single object and identity map. Then taking F : 𝒞 → 𝒟 and * : 𝒞 → 1, we have LF[*] ≅ colim F and RF[*] ≅ lim F

Groups

Let G be a group and H ≤ G be a subgroup. There is an inclusion iH : BH → BG.

Given a representation F : BH → Vec, the LKE is the induced representation LF[iH] ≅ k[G]⊗k[H]− and the RKE is the coinduced representation RF[iH] ≅ Homk[H](k[G], −)

Generating a vector space by a basis

We view a basis as a discrete category ℬ. We view an individual vector space by a functor from the terminal category V : 1 → Vec

Now take * : ℬ → 1 and let k : ℬ → Vec send every object to the ground field k. Then L*[k] ≅ V

And ε : k ⇒ *L*[k] ≅ V sends εb : k(b) → V by mapping 1 ∈ k to the basis element b ∈ V.
