Summary

Coxeter groups are those groups that have presentations of the form

⟨x0, …, xn ∣ (xixj)mij = 1⟩, where M is a symmetric matrix with 1s on the diagonal (so xi2 = 1).

This determines a graph, called the Coxeter-Dynkin graph

Note that for i ≠ j we must have mij ≥ 2, since if mij = 1, that implies xixj = 1 so xi = xj−1 = xj.

When drawing the Coxeter-Dynkin graph you

  • don't draw any edges with mij ≤ 2
  • leave the mij = 3 edges unlabelled
  • label the rest of the edges.
