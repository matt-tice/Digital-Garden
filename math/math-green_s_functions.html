Summary

We take as our equation Dϕ = δ , where D = −∂t2 + ∂x2 + ∂y2 + ∂z2 − m2

This is where things get really interesting: we plug in a function ⟨ℱ−1[ϕ], ℱ[Df]⟩ = ⟨ϕ, Df⟩ = ⟨δ, f⟩ = f(0) So in general you get something non-zero on the right.

Now we can write ℱ[Df] = (−k02 + k12 + k22 + k32 − m2)ℱ[f]. And also ℱ[f(x)] = ∫e−ikxf(x)dx

f(x) = ℱ−1ℱ[f] = (2π)−4∫eikxℱ[f]dk

So f(0) = (2π)−4∫ℱ[f]dk = (2π)−4⟨1, ℱ[f]⟩, where (importantly!) 1 is a distribution, not a function. It's a distribution acting on functions in momentum space.

Now we have ⟨ℱ−1[ϕ], (−k02 + k ⋅ k − m2)ℱ[f]⟩ = f(0) = ⟨1, ℱ[f]⟩. Since this holds for all f, we get

(−k02 + k ⋅ k − m2)ℱ−1[ϕ] = 1

as a distribution

Solving this ends up leading to the propagators that show up in quantum field theory. There's lots of cool stuff there.

Example

Consider a really simple differential equation: ∂2G = δ(x) This is the Klein-Gordon equation in 0 + 1 spacetime for a massless particle.

Taking the Fourier transform on both sides gives k2G̃ = 1 So it's super easy to find the Green's function in the momentum space. The challenge is to pass back into position space

So we need to compute (up to scalars) $$ G(x) = \int^{\infty}_{-\infty }dk \dfrac{1}{k^{2}} e^{ikx} $$

The problem is that this integral passes through the singularity at k = 0. The standard way to fix this is to change the differential equation slightly; perturb it, if you will (∂2 + ε2)G = δ

This is now Klein-Gordon for a particle with a tiny mass ε. Here's the benefit: we now can write $$ ~{G}(k) = \dfrac{1}{k^{2} + \varepsilon^{2}} = \dfrac{1}{(k - i \varepsilon )(k + i\varepsilon )}, $$ moving the poles from zero to ±iε.

Now the integral technically is well-defined. If that's all you care about, you're done. But there's more work if you want to find a closed form. The issue with the closed form is that if you just do the integral directly, there are no elementary functions that have the antiderivative. So to do it, you use complex analysis

Cauchy Residues

The goal is to take a line/contour integral around the singularities and use Cauchy's residue theorem to pick off what the integral has to be.

So we integrate from −R → R and then use a semicircle to close the loop. We get ∫γ = ∫−RR + ∫C = 2πi∑ residues

So we need to do this in a way that the semicircle part of the integral ∫C will go to zero (or at least become something that has a closed form).

Now let's just look at the integral over the semicircle ∫C(k2 + ε2)−1eikxdk. Since C is living in the complex plane, we write k = u + iv, so the exponential eikx = eikue−vx

Basically now the idea is that as you expand out R, the semicircle needs to have larger and larger v in order to close things, and the semicircle integral goes to zero. But I think it's nicer to do this with the projective line

Real Projective Line

In order to use the Cauchy residue theorem, we need a closed loop, which is why we had to do this semicircle business. But instead we can just view the integral −∞ → ∞ as a integral around ℝP1 (which is diffeomorphic to a circle). The real projective line is embedded in ℂP1 (which is diffeomorphic to the sphere), as just the equator of the Riemann sphere.

We need to be a bit careful about how eikx works in this case, though. We end up with a singularity at ∞. But that's fine — this is basically where the semicircle comes back in.

Residue theorem: By the way, this theorem only needs your path to be piecewise smooth, so instead of using the arcs/semicircles that you always see in physics, people really should just be using a step function around the singularities — it's so much easier!

You basically just bound the integral around the singularity. So if we want to integrate around ∞, we can do it using calculus on manifolds by viewing the sphere as a manifold and picking a chart (or change coordinates) where w = 1/k, so dk = −dw/w2.

$$ \int_{C} \dfrac{1}{k^{2} + \varepsilon ^{2}}e^{ikx} dk =- \int_{C} \dfrac{1}{1 + \varepsilon^{2} w^{2}}e^{ix/w} dw $$

Now it's easy — just bound the integral $|- \int_{C} \dfrac{1}{1 + \varepsilon^2} w^{2}}e^{ix/w} dw| \leq \int | \ldots | = \int | (1 + \varepsilon^{2} w^{2})^{-1} | $

You can just bound the thing in the absolute value in your tiny path around the singularity; it'll depend on the size of the detour, and as you send that to zero you find that the part of the integral with the detour goes to zero, so we get that our integral is just entirely determined by the residues

The d/dx example

This is actually what we should probably start with: ∂G = δ. Then G̃ = 1/ki

We do the same type of regularization (ε is called a regulator by the way). So we end up with $$ \int dk \dfrac{1}{ik + \varepsilon } e^{ikx} $$

This gives the so-called causal green's function (which people also call "retarded", but that's not…my favourite word, so I'm going to avoid it)

The pole is located at k = iε, which is in the upper half plane. Since there's only one pole, our result is a bit different:

When x < 0 there is no pole to trap, since we pass into the lower part of the complex plane. The integral ends up giving zero.

When x > 0, we need to close in the upper half plane to make sure things stay bounded, so we pick up our residue

Residues

This is actually more subtle than I thought. The residue theorem says that you get the integral just reducing to the residues, but computing the residues can be tricky, depending on your singularities.

The residue is always the a−1 term of your Laurent series

Here we need to find $$ Res[\dfrac{e^{ikx}}{ik + \varepsilon }] $$

Since the singularity is at k = iε, we need to find the coefficient of $ \dfrac{1}{k - i\varepsilon } $ in the Laurent series of your function.

In this case if we expand everything out we have $$ \dfrac{1}{i} (\dfrac{1 + (ikx) + \ldots}{k - i \varepsilon }) $$

Oh but ok — technically you can do that, because exp is analytic, so you can expand it around zero, but then you need to change up the equation a bit, because you need to find the negative one coefficient in a Laurent series around the singularity, so having k/(k − iε) isn't going to fly.

So the easier way to do it is just to expand your exponential around the singularity: write eikx = eix(k − iε)e−εx = e−εx(1 + ix(k − iε) + …)

Now it works, and you get that the residue is $$ \dfrac{e^{-\varepsilon x}}{i} \rightarrow 1, \quad \text{as } \varepsilon \rightarrow 0. $$

So in this case our Green's function is

which is a step function

By the way, when x = 0 we have $$ \int_{-\infty}^{\infty} \dfrac{1}{ik + \varepsilon } = \dfrac{1}{2} $$

but it's essentially irrelevant, because we don't need to define G(x) everywhere, only almost everywhere.

Advanced propagator: We could do the same thing though, where we take ∂ − ε as our regularization. In that case you get the advanced propagator, which ends up being −θ(−x) (negative one on x < 0 and zero on x > 0)

Back to the original example

We have our two poles at ±iε. When x > 0 we go around the top one, and when x < 0 we go around the bottom

The interesting thing is what happens with the residues

Say x > 0, so we need to find the residue of $ \dfrac{e^{ikx}}{k^{2} + \varepsilon^{2}} $ at k = iε.

Cover-up: There's this thing called the cover up rule apparently, where if your singularity only has a single power in the denominator, then the residue is Resk = k0f(k) = limk → k0(k − k0)f(k)

So in this case, we get limk → iεeikx/(k + iε). So we get $$ \dfrac{e^{-\varepsilon x}}{2 i \varepsilon } $$

Similarly, $ G(x < 0) = \dfrac{e^{\varepsilon x}}{2 i \varepsilon } $, so in general $$ G_{\varepsilon }(x) \sim \dfrac{1}{\varepsilon } e^{-\varepsilon |x|} $$ But now we don't have any way to send ε → 0

Double pole: The way to fix it (or at least one way to) is to pick a different regularization: (∂ + ε)2 → (ik + ε)2 Now if we play the same game we have $$ \dfrac{e^{ikx}}{(ik + \varepsilon )^{2}} $$ which has an order two pole living at k = iε

The rule to find the residue in this case is $\mathrm{Res}\>{}_{k=k_{0}}f(k)=\lim _{k\rightarrow k_{0}}\frac{d}{dk}\Big[(k-k_{0})^{2}f(k)\Big]$

We get ixe−xε → ix as ε → 0

And similarly to the ∂ + ε case, we have no poles in the bottom half-plane, so we get (also there are factors of 2πi that cancel out) G(x) = xθ(x) This is the causal propagator. And just like the other case, we could have used −ε to get the advanced (anti-causal) propagator.

Klein-Gordon

Doing our Fourier transform, we have (−ω2 + k2 + m2)G = 1

Let $ E_{k} = \sqrt{k^{2} + m^{2}} $

So we have $$ G(\omega, k) = \dfrac{1}{E_{k}^{2} - \omega^{2}} = \dfrac{1}{(E_{k} - \omega )(E_{k} + \omega )} $$

This has singularities at ω = ±Ek

But in this case, these aren't just isolated singularities; since Ek depends on k, this is a whole sheet of singularities.

The way that you treat it, is you fix k and therefore Ek, and treat it like our ε. But now the singularity is sitting on the real axis, not in the imaginary part. But that's fine, we can just do what we did before, and add a new ε

If we take ω → ω + iε, the new poles are at ω = −iε ± Ek

Now we look into how we want to do our contour. If we have e−iωt then for t > 0 we go low, and for t < 0 we go high

So t < 0 will just lead to zero, since there's no pole in the higher part. So we're left with t > 0

Taking the residues, we have to look at $$ \dfrac{e^{-i \omega t}}{(\omega - E_{k} - i \varepsilon ) (\omega + E_{k} - i \varepsilon )} $$

We get $ \dfrac{e^{-it E_{k}} e^{- \varepsilon t}}{2 E_{k} } + \dfrac{ e^{it E_{k}} e^{- \varepsilon t}}{-2 E_{k} } $

We can send ε → 0 and we're all good

$$ G(t,k) = \dfrac{1}{E_{k}} \sin(E_{k} t) \theta(t) $$

Then we still need to transform back from k → x

Interpretations

One thing I didn't realize is that to do a Fourier transform we really need the function to decay to zero at ±∞. Actually more precisely we need f ∈ L1

This is actually what regularization does! That's kinda crazy actually.

Causal prop: For instance, consider the causal propagator, where we take ω + iε. We could write G̃(ω + iε) = ∫dtG(t)ei(ω + iε)t = e−εtG̃(ω)

This basically says that if you wanted the boundary conditions that G(t) = 0 for t < 0 and is non-zero for positive t, then in order to make sure you can do the Fourier transform at all, you first consider e−εtG, so that when t → ∞, your integral doesn't blow up. But from the equation above, that boundary condition ends up being the same as just shifting ω → ω + iε

Feynman: The Feynman propagator says that we're in the vacuum at t = ±∞, apparently. Supposedly you want to somehow show that with this prescription, everything dies off except the Ek = 0 terms as t → ±∞.
