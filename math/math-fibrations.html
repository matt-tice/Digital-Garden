Definitions

Total and base space

Given any functor F : 𝒞 → 𝒟 we call 𝒞 the total space, and 𝒟 the base space.

Strict fiber of a functor

For any object B ∈ 𝒟, the strict fibre 𝒞B is 𝒞B = {(A,f) ∣ F(A) = B and F(f) = idB}

Every strict fiber gives us a category whose objects are the objects A and morphisms are the morphisms f for all (A,f) ∈ 𝒞B. Note that each f, since it gets sent to idB, must be a map between two objects A1, A2 with F(A1) = F(A2) = B, so f sits inside the induced category.

By abuse of notation, we'll denote the induced category as 𝒞B as well.

Vertical morphisms: The morphisms in the category 𝒞B are called vertical

Essential fibre of a functor

For any object B ∈ 𝒟, the essential fibre F−1(B) is F−1(B) = {(A,f) ∣ F(f) : F(A) → B is an isomorphism}

So it's basically the comma or slice category over the object B, but you restrict to only considering isomorphisms.

F−1(F(B)) = {(A,f) ∣ F(f) : F(A) → F(B) is an isomorphism}

This will include all objects isomorphic to B: if A≅fB then (A,f) ∈ F−1(F(B))

But not everything in the fiber will be of this form.

Cartesian

A morphism f : A → B in 𝒞 is called F-cartesian (or just cartesian) if the following universal property is satisfied:

For all F(h) : F(X) → F(B) and ϕ : F(X) → F(A) such that F(h) = ϕF(f), there is a unique g : X → A such that ϕ = F(g) and gf = h.

Grothendieck fibration

F : 𝒞 → 𝒟 is a Grothendieck fibration if for all ϕ : A → F(B), there is some cartesian map f : X → B such that ϕ = F(f).

The choice of f for all ϕ is called a cleavage

Fiber: Taking the essential fiber

Discrete fibration

A Grothendieck fibration is discrete if there is a unique f : X → B with ϕ = F(f).
