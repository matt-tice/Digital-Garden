Regular Value of a Curve

Let γ : I → ℝn be C1. Then c ∈ ℝn is regular if

γ′(t) ≠ 0 for all t such that γ(t) = c.

If every element of the image is regular, then γ is called a regular curve.

Intuition

The regular values are the places where γ was drawn with a flowing hand — the curve never stopped in these places, which prevents cusps, corners, etc.

More precisely, if γ′(t) = 0, then we can't tell what the curve looks like when we move slightly to the left or right: is it increasing or decreasing? So if the function isn't constant, and the value of γ eventually changes, then it must be a sudden change that can't be accounted for infinitesimally.

  • this is a corner, cusp, etc.

  1. Note

    The curve gamma contains the data of all of the components — consider a circle, parameterized by γ(t) = (sint,cost). The top of the circle has zero slope, but the derivative of gamma is not zero! γ′(0) = (1,0)

    This is part of the value of taking curves to be the entire data of the function's graph, and not just one of the coordinates; it makes it easier to avoid singularities, as long as they don't appear in all coordinates simultaneously.
