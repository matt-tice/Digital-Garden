Symmetric sequence

Let C be a set. Define S[C] to be the category whose objects are pairs (A, f), where A is a finite set and f : A → C is a set map. Morphisms (A, f) → (B, g) in this category are maps ϕ : A → B such that f = g ∘ ϕ

A symmetric sequence is a functor F : S[C] × C → 𝒱
