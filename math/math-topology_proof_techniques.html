Tube arguments

Idea: Take a bunch of local neighbourhoods around slices of a compact set, and then use compactness to glue all these slices together

example: tube lemma

Let X, Y be topological spaces with Y compact. If U ⊆ X × Y is open, then for any {x0} × Y ∈ U, there is an open neighbourhood u ∈ V ⊆ X such that V × Y ⊆ U

Proof

Since U is open, we can find open neighbourhoods in the product topology containing (x0, y) for any y ∈ Y. In particular, we can take these neighbourhoods to be basis elements: (x0, y) ∈ Vy × Wy ⊆ U.

Compactness: Since Y is compact and ∪yWy = Y, we can find a finite subcover ∪iWyi = Y.

Intersection: We take V = ∩iVyi which is an open set (since it's a finite intersection) which contains x0.

Now (x, y) ∈ V × Y implies x ∈ Vyi for all yi, and y ∈ Y = ∪iWyi. So there's some yj for which (x, y) ∈ Vyj × Wyj ⊆ U.

Thus (x0, y) ∈ V × Y ⊆ U.

Intuition

The tube lemma says that we can widen any slice in an open set into a tube, as long as the length of the slice is compact.

Example: Projections with compactness are closed

Let Y be compact. Then for any space X, the projection map π1 : X × Y → X is closed.

Proof

Let C ⊆ X × Y be closed. We'll show that π1(C)c is open. Take any x0 ∈ π1(C)c. Then {x0} × Y ⊆ (X × Y) \ C = Cc.

Since C is closed, Cc is open.

Tube lemma: We apply the tube lemma to get an open neighbourhood (x0, y) ∈ V × Y ⊆ Cc. Note that if v ∈ π1(C) then (v, y) ∈ C , so (v, y) ≠ V × Y ⊆ Cc and thus v ≠ V. So V ∩ π1(C) = ⌀.

We have thus found an open neighbourhood of x0 entirely contained in π1(C)c. Thus π1(C)c is open.

Intuition

The idea of the proof is very simple: we take any point x0 outside of π1(C) and consider the slice over it. We can then enlarge the slice to a tube. In the projection, the widening corresponds to creating an open neighbourhood around x0 which doesn't intersect π1(C).
