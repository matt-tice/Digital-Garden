Measure on a measurable space

Let (X,Σ) be a measurable space (a set and a sigma algebra). A function μ : Σ → [0,∞] is a measure if $\mu(\sum_{k=1}^{N} A_{k}) = \sum_{k}_{}_{=}_{1}^{N} \mu(A_{k}) $ where A + B denotes the union of two disjoint sets.

Notes

Empty measure: Most times you'll see also the condition that μ(∅) = 0, but this is satisfied automatically as long as there's at least one set of finite measure, since μ(A) = μ(A+∅) = μ(A) + μ(∅) so if μ(A) < ∞ , we can subtract it from both sides, to get μ(∅) = 0.

Countable additivity: Usually this is assumed, but I'd like to do as much as I can in the finite world before switching to the countable case.

Theorems

Monotone

Let μ be a (non-signed) measure. If A ⊆ B then μ(A) ≤ μ(B).

Proof

We have μ(B) = μ(A+B\A) = μ(A) + μ(B\A) ≥ μ(A)

since μ(B\A) ≥ 0.
