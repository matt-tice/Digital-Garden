Let hA = Hom(A,-) and hB = Hom(-,B)

hA(f) = Hom(A,f) = the set map that sends g → gf (do g then do f)

hB(f) = Hom(f, B) = the map that sends g → fg (precomposing with f)

hf: hB → hA by

hf(X): hB(X) → hA(X) which sends g: B → X to fg: A → X

So hf(X) = hX(f). So a way to remember is to recall that X is always above f

Similarly, hf: hA → hB given by sending g: X → A to gf : X → B

Thus hf(X) = hX(f)

Yoneda Embedding

We have Nat(hA , hB) ≅ hB(A) = Hom(B,A)

Then the map C → SetC given by A → hA is a contravariant functor that is fully faithful So Cop is embedded in SetC.

Similarly, Nat(hA , hB) ≅ hB(A) = Hom(A,B)

Giving a fully faithful covariant functor C → SetCop

In this way, we can think of C as being embedded in the category of presheaves on it.

In fact we have that Cop  ≅ hA|A ∈ C and C  ≅ hA|A ∈ C

In algebraic geometry and topos theory, we will often think of categories as categories of presheaves, and determine whether the presheaves are actually sheaves.

This corresponds to saying that our category is a Grothendieck topos.
