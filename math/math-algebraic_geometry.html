Sieves

A sieve on an object B is a subfunctor of Mor(-,B) = hB

In other words, it's a collection of morphisms that point into B.

Denote a sieve on B by sB Similarly, a cosieve is sB

Explicitly

A subfunctor F of Hom(-,B) is a presheaf such that F(A) ⊆ Hom(A,B) and F(f) is the restriction of hBf. Say f: A → X F(f): F(X) → F(A) ⊆ Hom(A,B)

But for there to be such a map, if F(X) ≠ ∅, it must be the case that F(A) ≠ ∅ So we have that if g ∈ F(X), so g: X → B then F(f)(g) = fg: A → X → B must be an element of F(A)

Conclusion

  1. If sB(A) is non-empty, then so is sB(X) for all X that map into A (ie. have some X → A)
  2. If g ∈ sB(X) then fg ∈ sB(A) for all f: A → X

In this way, sB is something like a collection of left ideals

Conclusion

It follows then that it's rare for sB(B) to contain 1B: if it did, it would also contain all morphisms into B. So we'd have sB = hB

So 1B ∈ sB iff sB = hB.

Then hB is something like the full ring and sB is an ideal

Ring Theory

Say we have a one-object category { * }. Then hB is the monoid of all morphisms in the category, and sB is a sub-monoid closed under left multiplication by any element in hB

In the case of enriched categories, taking abelian enrichment turns hB into a ring, and sB into literally an ideal

Intuition

A sieve is something like a filter: it picks out regions of B

We can think of a sieve as an ideal in a ringoid (but not literally in a ringoid)

Partial Order

Let sB ≤ tB iff sBA ⊆ tBA for all A. Define the union and intersection objectwise (sB ∪ tB)(A) = sBA ∪ tBA (sB ∩ tB)(A) = sBA ∩ tBA

Then you get that for any fixed B, the collection of all sieves forms a complete lattice.

Pullback

Let sB be a sieve and f: A → B. We get a sieve f* sB called the pullback, defined by

(f* sB)(X) = { g: X → A | gf ∈ sB (X) }

This is actually the pullback in the categorical sense:

We take sB ×hB hA = f* sB

This sends X → sB(X) ×hB(X) hA(X), which we compute in Set:

This is { (g,h) ∈ sB(X) × hA(X) | g = hf }

Notation

Personally, I don't like the f* notation for the pullback. I'll denote the pullback by

sB / f

since it corresponds to the set of h: A → X such that hf ∈ sB

Grothendieck Topology

For each object, we get a sieve. So think of our sieves as collected into a map S: C × C → Set

The weird thing is that we want more than one sieve for each object. We choose a collection of sieves, which we call covering sieves. They have to satisfy the following:

Axioms

  1. hB is a covering sieve for all B

  2. If sB is covering and f:A → B then sB/f is covering.

  3. Let sB be covering and tB be any sieve. If tB/f is covering for all f ∈ sB(A), for all A, then tB is also covering

This is a much nicer way of looking at Grothendieck topologies, I think — it's very algebraic The conditions become

  1. We have a special element hB
  2. We're closed under pullback
  3. We have a kind of ideal/multiplicative closure

Let's define tB/sB to be all of the sieves of the form tB/f, with f ∈ sB(A) for some A.

Then we say that if tB /sB is covering, then so is tB

Sections

Given a contravariant functor F mapping into Set, we call the set F(X) the sections of F over X

From the Yoneda lemma, we have Hom(hB, F) ≅ F(B) naturally. So we can identify the elements of Hom(hB , F) with the sections.

We associate the two with η → ηB(1B) And if x ∈ F(B), we take ηA: hB(A) → F(A) to be the map which sends f: A → B to F(f)(x) ∈ F(A)

So ηx = F(-)(x) is the corresponding natural transformation

Sheaves

These are ways of taking something local and turning it into something global

Definitions

A separated presheaf is a contravariant functor F, such that given any covering sieve sB, the map

Hom(hB, F) → Hom(sB, F)

is injective.

A sheaf on a site is a contravariant functor F, such that given any covering sieve sB, the map

Hom(hB, F) → Hom(sB, F)

is a bijection.

A η: hB ⇒ F is determined by ηB and what it does to 1B What is ηB doing on sB?

ηB: sBB → F(B)

We don't necessarily have that 1B ∈ sBB

Consequences

The map above sends a natural transformation (a section of the presheaf) η: hB → F to basically the same transformation, just restricted to sB

So this basically says that every covering sieve has 'enough space' to contain all of the possible transformations hB → F. My guess is that means something like the covering sieves are all global?
