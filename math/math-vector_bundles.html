Smooth vector bundle of rank n

Let M be a smooth manifold. A smooth vector bundle of rank n over M is a bundle π : E → M where each fiber π−1(x) is a vector space of dimension n, and

Locally trivial: For all x ∈ M, there is a neighbourhood Ux and a diffeomorphism ϕ : π−1(U) → U × kn such that

ϕ|π−1(x) : π−1(x) → {x} × kn ≅ kn is a linear isomorphism

π ∘ ϕ−1(x,v) = x for all v ∈ kn[2026-09-21 Mon 14:27].

Sections of a bundle

Given a vector bundle π : E → M, a section is a map σ : M → E such that σπ = 1M.

Similarly, you can define a section on any open set in M.

Notation: We write the sections on an open set U as Γ(U).

Sheaf: Sections form a sheaf

Connections

A connection is a linear map of sheaves

∇ : Γ(M) → ΩM1⊗𝒪MΓ(M)

such that

Leibniz rule: ∇(fσ) = df ⊗ σ + f∇(σ)

where 𝒪M is the sheaf of regular or holomorphic functions on M.

Directional derivative

Given any vector field ζ we define the directional derivative with respect to ζ by ∇ζ(σ) = ⟨∇(σ), ζ⟩

Intuition

The connection allows us to define a first (directional) derivative. To get higher derivatives, we need to extend ∇ to act on higher differential forms.

Flat / integrable connection

A flat or integrable connection is a connection such that [∇α,∇β] = ∇[α,β] for all vector fields α, β.

Intuition

When the connection is flat, the only way parallel transport can be path-dependent is when paths wrap around singularities
